N Launcher 0.0.20 adds an in-app language toggle between **Português** and **English**:

- **Language switcher (`L — App settings / Ajustes do aplicativo`)**: Toggle between `Português` and `English` with immediate UI update. Saved as `language=pt` or `language=en` in `/switch/n-launcher/menu.cfg` without modifying existing settings, profiles, cache or saves.
- **Full frontend localization**: Library, folder picker, game options, per-game memory settings, updater prompts, and Switch status/dialog messages are translated in both Portuguese and English.

Update through `[R]` in N Launcher, return to hbmenu, and reopen the updated NRO. Game data, memory profiles and saves are preserved.
