N Launcher now checks for new releases when it opens.

- Startup checks are enabled by default and run once per application session.
- Confirm an available version before downloading or installing it. A newly displayed prompt requires a fresh confirmation press.
- Use **L — App settings** to disable startup checks. The preference is saved, and **R — Updates** remains available for manual checks.
- A failed or canceled startup check returns to the library. Update logs use a separate file so they do not overwrite game preparation logs.
- Game runtime, cache format, saves and memory profiles are unchanged.

Install from 0.0.9/0.0.10 using R if the corrected TLS transport works on your console, or extract the ZIP to the SD card. Once 0.0.11 is installed, opening the app starts the automatic check. Console validation of the complete update flow is still pending.

The Elliot preparation crash remains under investigation. Its separate diagnostic build is not included in this release; this update does not claim to fix that crash.
