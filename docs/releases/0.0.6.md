N Launcher passa a oferecer atualizações pelo próprio console e perfis de memória por título.

- Pokopia splitado validado com imagem, som, controles, salvar e carregar.
- Mantida a correção do fechamento no preflight: interface com libounce_core/newlib.
- **R — Atualizações:** consulta o GitHub, confere download/arquivo e preserva a versão anterior até a nova abrir.
- **Y → Memória por jogo:** limite do jogo e reserva do carregador persistentes, com restauração para Automático.
- Nome e estrutura padronizados: `/switch/n-launcher/n-launcher.nro`.
- Migração dos dados de `nx2-link` por renomeação; cache e saves preservados, conflitos não sobrescritos.
- Build, ZIP, manifesto e checksums gerados no GitHub após testes e verificação dos NROs.

Extraia o ZIP no SD e abra a nova versão pelo hbmenu. Esta primeira instalação com atualizador é manual; as próximas versões poderão ser instaladas pelo botão R. Não é necessário reativar kaiHEN para trocar o NRO. Evite abrir builds de diagnóstico antigas depois da migração.

O aplicativo continua experimental. O resultado do Pokopia não garante outros títulos; perfis alterados, migração e HTTPS nativo requerem seus próprios testes no console. O cache já preparado não precisa ser refeito.
