N Launcher 0.0.21 upgrades the embedded generic runtime snapshot to **nx2-flow 0.2.6 (loader 0.1.7)** while preserving N Launcher's split-NUP backend, >64 MiB SD cache, per-game memory profiles and saves:

- **Add-On Content (`kind = 2`) support from NUPs:** mounts DLCs and Switch 2 Edition Upgrade Packs directly from NUP files.
- **Save & cache storage improvements:** SD-backed `FsSaveDataType_Cache` directories, Switch 1 → Switch 2 read-only save migration (`cmd 53`), and `IFileSystem::GetFileSystemAttribute` (`cmd 16`).
- **Offline BCAT & preselected user fallbacks:** built-in `bcat_offline.h` and `preselected.c` prevent aborts when the host title lacks BCAT storage or already consumed the preselected user launch parameter.
- **NPDM memory metadata & large-BSS room:** reads `main.npdm` remote-memory / system-resource limits directly from NUPs (automatically giving full free heap to 0 MB sysres titles) and keeps 1536 MiB initial room (trimmed back to the kernel after open) for titles with >1 GiB static `.bss`.
- **Priority-lock backoff & raw FS:** upstream `spinlock.h` and `fs_raw.h` included natively.

Update through `[R]` in N Launcher, return to hbmenu, and reopen the updated NRO. Game data, memory profiles and saves are preserved.
