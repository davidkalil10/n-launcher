N Launcher 0.0.17 fixes two title-compatibility bugs found in console testing:

- **Empty 0-byte NUP entries (`Invalid payload offset/codec`)**: `Archive::file()` and `Archive::read()` now accept valid 0-byte uncompressed files (`size == 0`, `stored == 0`, `codec == 0`) stored with `offset == 0` in the NUP TOC, while continuing to reject non-empty payloads whose offset overlaps header/TOC metadata or uses unsupported codecs.
- **Switch 2 titles with 5+ GiB fixed heaps and no `VirtualAddressMemory` entry in `HeapDef.byml`**: Backported the `nx2-flow 0.2.6` `byml_scan_heaps` detection and VAM fixed-heap headroom trim via `tools/runtime_patches.py` (keeping the pinned `third_party/nx2-flow` snapshot intact) so titles that reserve address space in code receive the console's 8992 MiB budget instead of starving `nn::os::AllocateMemoryBlock` at boot.

Update through `[R]` in N Launcher, return to hbmenu, and reopen the updated NRO. Game data, memory profiles and saves are preserved.
