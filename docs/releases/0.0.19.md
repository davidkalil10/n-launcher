N Launcher 0.0.19 fixes a save-filesystem abort in titles that call `IFileSystem::GetFileSystemAttribute` (command 16, HOS 15.0+):

- **Save filesystem command 16 (`tools/runtime_patches.py`)**: Backported the `nx2-flow 0.2.6` `inline_request_size()` check and `cmd == 16` (`GetFileSystemAttribute`, 0 paths) pass-through in `rom.c` so titles like Red Dead Redemption Nintendo Switch 2 Edition do not abort with `0x2ee202` after writing initial save/options files.

Update through `[R]` in N Launcher, return to hbmenu, and reopen the updated NRO. Game data, memory profiles and saves are preserved.
